# 订阅说明

**Token Plan** 是面向 AI 编程场景推出的专属订阅方案，您可使用高性价比的订阅资源包，在各类主流 AI 开发工具中调用 MiMo 旗舰大模型。

## 核心优势

  * **覆盖旗舰模型** — 支持 mimo-v2.5-pro、mimo-v2.5、mimo-v2.5-asr、mimo-v2.5-tts-voiceclone、 mimo-v2.5-tts-voicedesign、mimo-v2.5-tts，包括 V2 系列共 9 款模型。采用 Token 折算机制，额度透明可控

  * **弹性订阅方案** — 四级梯度套餐，满足个人开发至企业级开发需求

  * **多生态开箱即用** — 兼容 OpenCode、OpenClaw、Claude Code 等主流开发工具链

## 套餐购买

  * **支持套餐补差价升级：当前平台仅支持同时购买 1 个套餐，如在套餐过期之前想获得更多额度** ，可将你已使用的 Credit 额度换算为对等金额，在此基础上补差价以升级至更高套餐，获得更多 Credit。支持跨等级的套餐补差额升级，不支持套餐降级。若已经升级至最高档 Max 套餐，无法继续升级。**套餐到期后，可再次购买任意等级的套餐。**

> 差价 = 新套餐价格 -（原套餐剩余额度/原套餐总额度）* 原套餐价格

  * **支持自动续费** ：已上线自动续费功能，首次开通连续订阅享受折扣，请保持关注。

  * **暂不支持退款** ：请注意，订阅服务一经购买即生效，不支持退款。套餐内额度未用完亦不予退费，请您根据自身使用需求审慎选购合适的订阅方案。

  * **支持开票** ：国内用户可以按充值明细的交易订单申请开票，实际可开票金额为实际支付金额。海外用户在购买后可直接下载发票，或在充值明细页面中下载发票。

## 套餐使用

Token Plan 套餐额度仅可在编程工具（如 OpenClaw、OpenCode 等）中使用，禁止以 API 调用的形式用于自动化脚本、自定义应用程序后端等明显非 Coding 场景的请求行为。

若使用套餐对应的 API Key 进行超出许可范围的调用，将被视为违规或滥用行为，平台有权对相关订阅采取暂停服务、封禁 API Key 等处理措施。

## 快速指南

快速上手 Token Plan，从订阅套餐到在编码工具中使用 MiMo 模型。

### 订阅 Token Plan

访问 [Token Plan](<https://platform.xiaomimimo.com/#/token-plan>)，按需选择并购买合适的订阅套餐。

### 获取套餐专属的 Base URL 和 API Key

订阅成功后，可前往 [Token Plan](<https://platform.xiaomimimo.com/#/console/plan-manage>) 页面 ，获取套餐专属的 Base URL 和 API Key。

  * **API Key** ：在 [Token Plan](<https://platform.xiaomimimo.com/#/console/plan-manage>) 页面，获取专属 API Key（格式为 `tp-xxxxx`）。

  * **Base URL** ：后续需在 AI 编程工具中配置以下其中一个Base URL（ **协议因工具而异，Base URL 以** [**Token Plan**](<https://platform.xiaomimimo.com/#/console/plan-manage>) **页面展示为准** ），具体操作请参见对应的 AI 编程工具使用指南文档。

    * **OpenAI 兼容协议**

      * 中国集群：`https://token-plan-cn.xiaomimimo.com/v1`

      * 新加坡集群：`https://token-plan-sgp.xiaomimimo.com/v1`

      * 欧洲集群：`https://token-plan-ams.xiaomimimo.com/v1`

    * **Anthropic 兼容协议**

      * 中国集群：`https://token-plan-cn.xiaomimimo.com/anthropic`

      * 新加坡集群：`https://token-plan-sgp.xiaomimimo.com/anthropic`

      * 欧洲集群：`https://token-plan-ams.xiaomimimo.com/anthropic`

**注意事项**

  * 请妥善保管您的 API Key，不要泄露给他人。
  * API Key 仅在您所订阅的 Token Plan 套餐有效期内可用。
