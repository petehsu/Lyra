# 其他

## 模型下线

随着 MiMo 模型的持续迭代，新版本在效果与性能上已全面超越旧版本。我们将逐步下线历史模型，具体计划会通过短信、邮件及网站公告等方式提前通知，请留意相关消息并及时完成切换。已下线、即将下线的模型信息，详见 [模型下线](<https://mimo.mi.com/docs/zh-CN/updates/deprecate>) 。

## 模型能力与更多使用方法

### Xiaomi MiMo 模型如何体验？

  1. 普通用户可直接通过官方网页 **Xiaomi MiMO Studio（**[**https://aistudio.xiaomimimo.com**](<https://aistudio.xiaomimimo.com/>)**）** 在线体验

  2. 开发者可通过小米官方渠道获取资源：

  3. GitHub 仓库（<https://github.com/xiaomimimo/MiMo-V2-Flash>）获取开源的模型权重与代码

  4. Xiaomi MiMo 开放平台（<https://platform.xiaomimimo.com/>）申请API服务

  5. 另外需要说明：小米目前未推出官方的 MiMo 独立 APP，非官方渠道的相关下载软件存在安全风险，请勿下载

  

### 模型支持本地部署吗？如何进行本地部署？

此次发布的大模型已开源，请见：<https://github.com/XiaomiMiMo/MiMo-V2-Flash> 。本地部署优先支持 sglang，相关问题请参考：<https://github.com/sgl-project/sglang/pull/15207> 。

  

### 为什么对话过程中总是出现“服务器繁忙，请稍后重试”？

当前 MiMo 输出受到服务器载荷、提问内容、模型输出等各方面因素影响，您可以重建新的对话或者尝试重新生成，以获得更好的交流体验。

  

### 模型何时支持上传文件的功能？

后续会尽快支持，请耐心等待。
