# MiMo 模型公测限免延长公告

尊敬的各位开发者，

mimo-v2-flash 发布以来，受到了全球用户的广泛关注和热情支持，感谢大家对 MiMo 模型的有力认可与宝贵反馈！为了回馈广大开发者的热情支持，我们决定继续延长公测限免时间！现将相关调整公告如下：

### 限免时间延长 20 天！

原定于 2025 年 12 月底结束的免费试用期，将延后至 **2026 年 1 月** **20 日** **14:00（北京时间）** 。在此期间，用户可继续免费使用 mimo-v2-flash 模型 API，使用其核心功能，包括高效文本生成、代码处理等。此次延期旨在回馈广大用户的信任与支持，同时鼓励更多用户参与测试，提供宝贵反馈，我们将进一步优化模型性能、提升用户体验，并确保在正式发布前进行全面的安全测试。

### 支付能力系统上线预告

XiaomiMiMo API 开放平台的支付能力系统将于公测结束前启用，并进行为期一周左右的试运行（具体试运行阶段以后续公告为准）。试用期间用户可进行账户充值，但服务暂不计费，试运行结束后将自动开始计费并消耗余额。为不影响正常使用，保证自身服务稳定，建议大家提前充值账户。

附模型 API 定价：**国内：输入 ¥0.7 / 1M tokens，输入（命中缓存）¥0.07 / 1M tokens，输出 ¥2.1 / 1M tokens；海外：输入 $0.1 / 1M tokens，输入（命中缓存）$0.01 / 1M tokens，输出 $0.3 / 1M tokens** 。更多详情将于近期公布，敬请关注官网公告更新及开放平台微信群通知。

我们诚挚邀请新老用户把握延长的免费公测期，继续畅享 MiMo 带来的智能体验，并积极分享您的使用心得和建议。如有疑问，请随时 [联系我们](<https://platform.xiaomimimo.com/#/contact>) 或加入开发者交流群（扫描左下角二维码加入），让我们一起探索智能的边界。

**—— Xiaomi MiMo API 开放平台团队**
