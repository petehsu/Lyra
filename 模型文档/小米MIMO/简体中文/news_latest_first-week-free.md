# Xiaomi MiMo 联合全球顶级 Agent 框架开启首周限免

![图片](/static/EegPbBoamoBsbBxquXtc4bAfnsb.a1cba175.png)

mimo-v2-pro、mimo-v2-omni 和 mimo-v2-tts 现已发布。为了满足全球开发者对 Xiaomi MiMo 系列全新基座模型的期待，Xiaomi MiMo 联合 OpenClaw、OpenCode、KiloCode、Cline 和 BLACKBOXAI 五大 Agent 框架，向全球开发者开放为期 1 周的免费 API 接口。

**注：mimo-v2-pro、mimo-v2-omni 仅在上述五大 Agent 框架中可免费使用，使用说明详见下文；如需直接调用模型 API，相关定价标准请参见** [**定价与限速**](<https://mimo.mi.com/#/docs/pricing>)**。**

## 01 / OpenClaw

**已限免支持** — 备受瞩目的通用 Agent 框架，真正能做事的 AI。

![图片](/static/Nx5QbEs3Yo8DygxJMN2c3kxWnid.be47e03d.png)

#### 接入方式

申请 OpenRouter 的官方 API Key 并在你的 OpenClaw 中配置

  * 聊天中直接设置：'/model openrouter/xiaomi/mimo-v2-pro'（或 v2-omni）

  * 或终端中设置：'openclaw models set openrouter/xiaomi/mimo-v2-pro'（或 v2-omni）

  * 或修改配置文件：将 model.primary 设置为'openrouter/xiaomi/mimo-v2-pro'（或 v2-omni）

详见 [OpenClaw 通过 Openrouter 免费接入 MiMo-V2-Pro/MiMo-V2-Omni](<https://mimo.mi.com/#/docs/integration/openclaw-with-openrouter>)。

![图片](/static/ATLBbB6IvojvQaxO2FycmVG8neh.4dccb57e.png)

## 02 / OpenCode

**已限免支持** — 开源 AI 编程代理。超 12w GitHub Star，每月超 500 万名开发者使用。

![图片](/static/LV1CbhblsoPquxxPB9zcop2Cnfe.b2273493.png)

#### 接入方式

终端界面、桌面应用及 IDE 扩展等编辑器中，选择 OpenCode -> Zen 中的 MiMo V2 Pro / MiMo V2 Omni（FREE标记）。

![图片](/static/MdVhbM8l0oKPjfxKUxHcDLEOnLp.2a70c950.jpeg)

## 03 / KiloCode

**已限免支持** — 面向软件开发者的全功能智能工程平台，超过 100 万 Kilo 开发者。

![图片](/static/EZ5vbEUuHou6z0xZyqGcDpCFnVe.c8c71f64.png)

#### 接入方式

终端界面及 IDE 扩展等编辑器中，选择 Kilo Gateway 中的 MiMo V2 Pro / MiMo V2 Omni（FREE标记）。

![图片](/static/TaZYbtPojoEYrhxy1VFcW8exnCG.5bf2b3dd.jpeg)

## 04 / Cline

**已限免支持** — 全球领先的 AI 编程助手，帮助开发者以倍速构建和重构高质量软件。

![图片](/static/IK8ybiYOWoLTgYxsRuBc0QpdnDg.6d72da44.png)

#### 接入方式

终端界面及 IDE 扩展等编辑器中，选择 Cline 作为 Provider，并选择 mimo-v2-pro 模型（FREE标记）。

![图片](/static/KZcgbkedCogQXCxHgAMcd2hYnsg.ba222395.jpeg)

## 05 / BLACKBOX.AI

全球增长最快的 AI 编程智能体之一，致力于用 AI 重新定义开发者编写代码的方式。

目前 [Blackbox.AI](<http://Blackbox.AI>) 还在最后调试阶段中，即将上线，请关注 [Blackbox.AI](<http://Blackbox.AI>) 官方 X 推文

![图片](/static/LSUEb0o9novt9FxiY6CcQfUgnbg.8980375e.png)

#### 接入方式

接入示意：终端界面、桌面应用及 IDE 扩展等编辑器中选择模型接入。

![图片](/static/H34obENPJoRUbdxngbycUkjonJd.0cf50e1e.jpeg)

## 06 / mimo-v2-tts

**长期限时免费** — 小米自主研发的语音合成大模型，让Agent 更能用有温度、有情感、有灵魂的声音与人对话。

#### 接入方式

通过官方API开放平台即可访问

[Xiaomi Mimo API 开放平台](<https://platform.xiaomimimo.com/#>)

具体调用可以参考：

[MiMo-V2-TTS 使用说明](<https://mimo.mi.com/#/docs/usage-guide/speech-synthesis>)
