# Xiaomi MiMo API 开放平台充值功能开放通知

尊敬的各位开发者：

感谢您对 Xiaomi MiMo API 开放平台的一贯支持，我们很高兴地宣布，平台充值功能于 **2026.1.20** 正式开放。为保障您服务的连续性，建议提前完成账户充值，避免计费系统上线后，因账户余额不足导致服务中断。

### mimo-v2-flash API 定价

  * 国内：输入 ¥0.7 / 1M tokens，输入（命中缓存）¥0.07 / 1M tokens，输出 ¥2.1 / 1M tokens

  * 海外：输入 $0.1 / 1M tokens，输入（命中缓存）$0.01 / 1M tokens，输出 $0.3 / 1M tokens

### 专属福利已送达

为感谢您的支持，我们已为所有新老用户准备了专属免费额度，您可登录后前往 [账户余额](<https://platform.xiaomimimo.com/#/console/balance>) 页面查收。

### 关于计费系统

计费系统将于近期正式上线，具体时间请以官方公告为准。在此之前，API 调用将继续免费开放，暂不消耗已充值金额或赠送的免费额度。

### 充值规则

  * 实名认证：中国大陆用户充值前需完成个人实名认证，企业认证功能暂未上线，敬请期待。

  * 充值：您可前往 [账户余额](<https://platform.xiaomimimo.com/#/console/balance>) 页面进行充值，中国大陆用户可选用**小米支付、支付宝、微信支付** 三种充值渠道，其他用户可选用 **Apple Pay、Google Pay、信用卡/借记卡** 等完成充值。

  * 查看余额：充值金额一般实时到账，您可在 [充值明细](<https://platform.xiaomimimo.com/#/console/recharge>) 页面查询充值订单及赠送金额，在 [账户余额](<https://platform.xiaomimimo.com/#/console/balance>) 页面查看当前余额。计费系统上线后，调用模型服务，将优先消费赠送金额，再消费充值余额。

  * 开具发票：中国大陆用户访问 [开具发票](<https://platform.xiaomimimo.com/#/console/invoice>) 页面，选择已充值成功的订单，申请开具电子发票。其他用户访问 [充值明细](<https://platform.xiaomimimo.com/#/console/recharge>) 页面，下载订单收据。

  * 更多内容详见 [常见问题](<https://mimo.mi.com/#/docs/faq?target=%E4%BB%98%E8%B4%B9%E9%97%AE%E9%A2%98>) 。
