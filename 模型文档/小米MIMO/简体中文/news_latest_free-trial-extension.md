# Xiaomi MiMo Agent 框架调用限免活动延长一周

自 26 年 3 月 19 日 Xiaomi MiMo-V2 系列新模型全球发布以来，mimo-v2-pro/omni 受到全球开发者的热情追捧和广泛关注，尤其是旗舰模型 mimo-v2-pro 在 OpenRouter 全球调用量排名中**蝉联日榜、周榜、趋势榜 Top1** 。

此外，我们与 **OpenClaw、OpenCode、KiloCode、Cline 、BlackBoxAI** 等顶级 Agent 框架共同开展的联合运营活动也深受用户喜爱。

因此，我们决定 —— **将「XiaomiMiMo 联合全球顶级 Agent 框架开启首周限免」活动由原定的限免一周延长为两周** **，** 免费时间将延长至： **北京时间（GMT+8） 2026年4月2日晚12点。**

各平台限免接入方式，请参考：[Xiaomi MiMo 联合全球顶级 Agent 框架开启首周限免](<https://mimo.mi.com/#/docs/news/first-week-free>)

AI 无门槛，创新不设限。诚邀全球开发者尽情释放 Xiaomi MiMo 大模型与顶级 Agent 框架结合的强大生产力。
