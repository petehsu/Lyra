# 账号与认证

### 国内/海外

  * **海外用户和国内用户有什么区别？**

主要区别：

1）支付方式不同（国内支持微信、支付宝、小米支付；海外通过 waffo 收银台支付（以美元 $ 结算））。

2）根据账号所在地区返回不同的 Base URL + Key，不互通。

3）海外版暂无开票功能。

  * **国内和海外的用量可以聚合计算吗？**

不可以。根据账号所在地区返回不同的 Base URL 和 Key，用量是分开计算的。

  

### 支持哪些登录方式？

平台使用小米账号登录，如已注册过小米账号，可直接登录；若无小米账号，可访问控制台进行注册，或在 [id.mi.com](<https://id.mi.com/>) 提前注册：

  * 中国大陆用户注册方式

    * 手机号注册

    * 三方账号授权注册（支持微信、微博、QQ、支付宝和 Apple ID 注册，为保证账号安全，可能会使用第三方账号绑定常用手机号）

  * 海外用户注册方式

    * 邮箱注册

    * 三方账号授权注册（支持 Google/Facebook 注册，为保证账号安全，可能会使用第三方账号绑定邮箱作为小米账号安全邮箱）

  

### 账号无法登录？

如有无法登录的问题，请访问 [小米账号帮助中心](<https://account.xiaomi.com/helpcenter?_locale=zh_CN>) 查看更多账号问题与解决方法。

  

### 充值/购买套餐需要实名认证吗？

国内用户充需要完成个人或企业实名认证后才能充值或购买套餐。两种认证类型都可以购买。

  

### 个人认证和企业认证有什么区别？

实名认证分为个人认证和企业认证，同一个账号只支持认证为一种类型。个人账号完成实名认证后可通过企业认证变更为企业账号，企业账号无法变更为个人账号。

**企业账号的支付流程和个人账号完全一致，** 企业账号也支持微信/支付宝/小米支付。

  

### 为什么提示“账号存在异常使用行为”，无法继续使用？

可能是因为系统在检测时捕捉到了某些关键词，触发了自动保护机制。我们非常重视每位用户的体验，会定期进行人工复核，以尽量避免误判的情况。如果您遇到这个问题，可以提供您的用户 ID，我们会尽快为您核实并协助解封。

  

### 小米账号注销后还能继续使用模型服务吗？

小米账号注销后，平台数据将一并清空，且 API Key 会同步时效。务必谨慎评估、谨慎操作。如有问题请联系我们 [support-mimo@xiaomi.com](<mailto:support-mimo@xiaomi.com>)。
