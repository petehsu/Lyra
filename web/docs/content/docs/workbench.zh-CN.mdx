## 标签、布局与导航

Workbench 标签可以承载搜索、网站、文件、编辑器、媒体、终端、设置、下载和 Agent 会话。标签可在支持的区域中选择、排序、移动，并从本机工作区状态恢复。处理依赖路径的内容前，请确认当前标签和项目。

{/* section:search */}
## 搜索

标题栏可以输入 URL 或搜索词。输入过程中，搜索建议可能向 Google Suggest 与 Wikipedia 发起请求；提交搜索或打开结果会联系所选搜索引擎或网站。查询文字属于发送给这些服务的数据。

{/* section:files-and-editor */}
## 文件与编辑器

文件管理器浏览本机路径并打开支持的文件；编辑器基于 Monaco 提供代码与文本编辑，并在可用时接入语言工具。文件操作和 Agent 修改会作用于真实文件，重要变更应使用 Git 或其他备份。

图片和 PDF 可在专用查看器中打开。能够预览不代表可以无损编辑；Lyra 也不承诺原生解析 Office 文档。

{/* section:downloads */}
## 下载

浏览器下载会出现在下载管理器，并写入本机目标目录。检查前应把下载文件视为不可信内容；打开或执行它可能触发 Lyra 以外的操作系统行为。

{/* section:terminal-and-git */}
## 终端与 Git

终端标签在选定工作目录中运行命令。Git 视图提供仓库状态、diff 与相关变更流程。命令、hook、仓库、凭证和远端服务仍由你负责。应用重启后，Lyra 不保证恢复每一个正在运行的终端进程。
