---

## 核心对象

1. 工作区标签：浏览、设置、文件管理、文件编辑、终端等都以标签承载。
2. 面板布局：左侧（AI/导航）、中间（工作区）、底部（终端）。
3. 统一菜单：右键菜单由全局菜单系统托管，风格与行为一致。

## 标签生命周期

Lyra 把标签行为抽为独立应用服务，统一处理：

1. 创建
2. 激活
3. 迁移（如终端区 `dock` 与工作区 `workspace`）
4. 关闭
5. 排序与拖拽

这样做的价值是：新增软件能力时，不再重写一套标签逻辑。

## 终端迁移

终端可在底部终端区和工作区标签之间双向迁移：

1. 右键菜单迁移
2. 拖拽迁移

迁移时保留会话，不以 React 卸载作为会话结束条件。

## 设计语言（高优先级）

1. 少即是多：去重复、去冗余。
2. 沉浸优先：减少重边框和强分割线。
3. 熟悉优先：创新不能让用户重新学习基本交互。
4. 融合标签：激活标签与内容区形成视觉融合，而非断裂。
