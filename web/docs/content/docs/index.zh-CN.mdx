Lyra 是一个面向 AI 时代的工作台，不是浏览器插件，也不是传统 IDE 外壳。

本页给你一条最短路径：先上手使用，再理解架构与边界。

## Lyra 的目标

1. 在一个工作区里统一浏览、代码、文件、终端与 AI 协作流程。
2. 用标签体系承载“软件化能力”，而不是继续堆叠网页页面。
3. 保持高性能与可演进架构，避免项目早期就进入巨石化。

## 你会在文档里看到什么

1. 运行与开发：如何启动、调试、排障。
2. 架构与边界：模块职责、依赖约束、守卫策略。
3. 工作区模型：标签生命周期、面板联动、拖拽迁移。
4. 文件与编辑器：文件管理、文件编辑、LSP 智能内核。
5. 多端适配：Linux 兼容策略与诊断链路。
