## 文档范围

这里是闭源 Lyra Desktop 应用的公开文档，只描述当前测试版已有能力，以及明确向外部开发者开放的接口。

Desktop 进程桥、runtime socket、存储 schema、内部 package 与 Agent ABI 等实现细节不是公开接口。仓库贡献者应阅读内部工程文档。

## 状态含义

产品成熟度使用 **Stable**、**Preview** 和 **Experimental**。Stable 表示测试版中可正常使用的功能；Preview 可能变化；Experimental 尚不完整或变化频繁，不应承载关键工作。

外部接口契约使用 **Supported** 与 **Preview**。Supported 开发者契约在同一 major 内保持兼容；Preview 契约变化会记录在开发者 Changelog，但不保证向后兼容。

Lyra 当前是免费测试版。“Stable”或“Supported”不代表付费 SLA、可用性承诺，也不保证第三方服务持续可用。
