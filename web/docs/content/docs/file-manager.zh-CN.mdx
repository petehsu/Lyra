## 定位

文件管理器不是“网页标签特判”，而是 `app tab` 体系下的独立软件。

它验证了 Lyra 的能力路线：

1. 软件能力可以在工作区标签中独立运行。
2. UI 层与原生能力层严格分离。
3. 后续插件/软件可以复用同一宿主机制接入。

## V1 能力范围

1. 目录浏览与导航（主页、目录、回收站）。
2. 收藏与最近位置。
3. 新建文件夹、新建文件。
4. 删除到系统回收站。
5. 回收站浏览、恢复、清空。
6. 列表与大视图切换（大视图支持图片预览）。

## 原生桥接原则

1. Renderer 不直接访问 Node `fs`。
2. 统一通过 preload + main + Rust NAPI 文件能力桥接。
3. 原生不可用时显示降级状态，不拖垮整个工作区。

## 图标与骨架策略

1. 文件类型 icon 使用统一注册表，禁止组件内散落后缀判断。
2. 加载态采用视图感知、数据感知骨架屏。
3. 骨架有节流策略，避免短时闪烁影响体验。
