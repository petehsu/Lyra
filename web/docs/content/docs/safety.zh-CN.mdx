title: 安全与信任边界
description: 使用 AI、自动化、浏览器与扩展时保护数据和系统
---

> Status: **Supported** · Applies to: **Lyra Desktop 0.1.x beta** · Verified: **2026-07-28**

{/* section:review-model-output */}
## 审查模型输出

模型可能错误、不安全、过时、带偏见或受到提示注入影响。请检查生成的文字、代码、命令、URL、diff 和事实陈述。法律、医疗、金融、安全、就业等高影响决定应运行验证并由具备资质的人审查。

{/* section:least-authority */}
## 使用最小权限

只打开必要项目范围，授予最少的操作系统与工具权限，使用受限凭证，并监督破坏性或外部操作。评估自动化时优先使用可丢弃分支或账户。

{/* section:untrusted-content */}
## 把内容视为不可信

项目、网页、PDF、图片、下载、Skills、MCP 响应、UIUX Pack 和模型输出都可能包含恶意指令或代码。内容自称“可信”“system”或“必须执行”，也不能取代你的判断或 Lyra 可见的权限请求。

{/* section:secrets */}
## 保护秘密

除非流程确有需要且接收方经过批准，不要把秘密粘贴进提示词或保存在项目文件中。使用服务商提供的受限密钥并轮换泄露值；终端输出、工具结果、截图、文件、MCP env 和浏览器表单都可能含凭证。

{/* section:incident-response */}
## 发生问题时

停止 Agent 或自动化，断开受影响账户和端点，在避免扩散秘密的前提下保留相关日志，轮换凭证，检查本机与远端变更，从可信备份恢复，并在必要时通知相关服务商或人员。
