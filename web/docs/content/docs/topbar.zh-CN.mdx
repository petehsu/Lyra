顶栏负责工作区的全局入口与窗口控制，是日常操作的最高频区域。

## 顶栏能做什么

1. 快速收起左侧面板，把空间让给中间工作区。
2. 快速收起底部终端，在阅读或编辑时保持专注。
3. 随时打开设置、文件管理器和官方文档，不中断当前上下文。
4. 使用系统窗口控制按钮完成最小化、最大化与关闭。

## 推荐使用顺序

1. 先用左侧/底部开关整理可视区域。
2. 再进入设置或文件管理执行具体操作。
3. 最后在需要时打开文档标签查阅说明。
