## Current line

Lyra Desktop is on the `0.1.x` free beta line. A source change or platform implementation does not become a released user feature until it is included in a published artifact and documented here.

{/* section:read-a-release */}
## Read a release

Before updating, check the exact version, available platform artifacts, feature-status changes, data migrations, provider changes, security notes, known issues, and rollback limitations. Back up important local data first.

{/* section:feature-status */}
## Feature status changes

Supported interfaces use the developer compatibility policy. Preview features may change with a Changelog entry. Experimental features may be removed or substantially redesigned. A page’s status banner is authoritative for that documented capability.

{/* section:release-notes */}
## Release notes

No production release history is asserted on this page beyond the current beta line. Published notes must be added only when a corresponding artifact exists. Developer-facing contract changes are listed separately in the [Developer Changelog](./developers/changelog).
