## 安装与系统要求

请使用为你的操作系统和架构正式发布的安装包。Lyra 需要受支持的桌面环境、可写的本机应用数据目录；云端功能还需要网络。终端、Git、本地模型与部分开发工具还依赖对应的命令行软件。

不要根据源码的平台适配推断安装包可用性。如果某个平台没有已发布的签名产物，就不属于当前正式分发范围。

{/* section:local-or-account */}
## 本地模式或账户模式

无需登录即可先使用本地模式。Google 登录的 Lyra 账户通过 Supabase 提供 profile 和会话能力，但不会自动把所有本机工作区或浏览器 profile 移到云端。退出登录也不会自动清除全部本机数据。

{/* section:first-workspace */}
## 创建第一个工作区

1. 打开 Lyra，创建或选择工作区。
2. 只打开你信任的项目目录；其中的文件或自动化说明也可能带来风险。
3. 按需添加浏览器、文件、编辑器、终端或 Agent 标签。
4. 要求 Agent 修改文件前，确认当前项目与工作目录。

{/* section:model-setup */}
## 配置模型

在设置中选择模型路径：

- 内置云模型服务连接；
- 自带服务商凭证（BYOK）；
- 自定义兼容端点；
- 本地模型端点。

先使用非敏感内容测试连接。“本地模型”只有在端点确实运行于本机且不向外转发时才是本地处理。

{/* section:first-safety-check */}
## 第一次 Agent turn 前

检查所选服务商、附件、项目目录、拟授予权限，以及浏览器或 Computer Use 工具是否启用。当前 Agent 上下文可能包含设备、仓库、本机身份线索、时区、屏幕信息和经授权的位置上下文；详见[设置与数据](./settings-data)。
