## Scope

This page targets Lyra commercial distribution users, not source-build workflows.

## Install and launch

1. Download the installer from official Lyra distribution channels.
2. Complete installation and launch the app.
3. On first launch, allow required local file and terminal permissions.

## Recommended first-time setup

1. Select language and theme in Settings.
2. Verify common folders are accessible in File Manager.
3. Run one simple command in terminal panel to validate runtime readiness.

## Core usage paths

1. Search and browse: enter URL or keyword from the home search input.
2. File and edit: double-click a text/code file in File Manager to open in a new editor tab.
3. Terminal workflow: run commands in bottom terminal and move to workspace tab when needed.

## Common issues

### Blank window or broken rendering

1. Restart Lyra first.
2. Verify graphics driver and desktop environment status.
3. On Linux, follow [Linux Compatibility](./linux-compat.mdx) safe-mode strategy first.

### File Manager or Terminal unavailable

1. Check OS-level permission denial.
2. Verify target directory read/write access.
3. If unresolved, export diagnostics and contact support.
