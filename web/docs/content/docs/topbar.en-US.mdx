## What you can do from topbar

1. collapse left panel to free workspace width
2. collapse bottom terminal for focused reading/editing
3. open Settings, File Manager, and Official Docs without losing context
4. use native window controls for minimize, maximize, and close

## Recommended workflow

1. arrange visible panels first
2. open settings/files/docs as needed
3. keep app-level controls in topbar and task-level work in workspace tabs
