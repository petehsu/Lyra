## Tabs, layout, and navigation

Workbench tabs can host search, websites, files, editors, media, terminals, settings, downloads, and Agent sessions. Tabs can be selected, reordered, moved between supported regions, and restored from local workspace state. Confirm the active tab and project before acting on path-sensitive content.

{/* section:search */}
## Search

The title bar accepts URLs and search text. Search suggestions may query Google Suggest and Wikipedia while you type; submitting a search or opening a result contacts the selected search engine or website. Treat query text as data sent to those services.

{/* section:files-and-editor */}
## Files and editor

File Manager browses local paths and opens supported files. The editor provides code and text editing backed by Monaco, with language tooling where available. File operations and Agent changes affect real files; use Git or another backup when the change matters.

Images and PDFs can open in dedicated viewers. Preview support is not the same as lossless editing. Office documents are not promised as natively parsed formats.

{/* section:downloads */}
## Downloads

Browser downloads appear in Download Manager and are written to a local destination. A downloaded file is untrusted until you inspect it. Opening or executing it can invoke operating-system behavior outside Lyra.

{/* section:terminal-and-git */}
## Terminal and Git

Terminal tabs run commands in a selected working directory. Git views expose repository status and diffs and can support change workflows. Commands, hooks, repositories, credentials, and remote services remain your responsibility. Lyra does not guarantee restoration of every running terminal process after an app restart.
