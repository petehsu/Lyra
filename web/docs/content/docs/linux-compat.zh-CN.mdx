## 目标

1. 在 Linux 下获得稳定、可预测的启动行为。
2. 遇到图形/驱动异常时可快速降级，不阻塞使用。
3. 形成可恢复的兼容状态，便于支持与发布前排查。

## 启动决策顺序

后端决策：

1. CLI 参数
2. 环境变量
3. 自动探测（Wayland/X11）

GPU 决策：

1. 安全模式（强制软件渲染）
2. 显式 CLI/ENV
3. 自动硬件渲染

## 运行时保障

1. Wayland/X11 环境变量互斥设置，避免误走错误后端。
2. 必要时禁用硬件加速，防止启动即崩。
3. 兼容状态落盘，支持后续恢复判断。

建议：遇到启动异常时先查看 Linux 兼容状态，再做后端/GPU 覆盖排查。
