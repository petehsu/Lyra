## 服务商路径

Lyra 可以使用云端服务商连接、用户提供的凭证（BYOK）、自定义兼容端点和本地端点。可用模型、认证、计费、保留、训练用途、处理地区与限流由端点运营方控制。

{/* section:data-sent */}
## 每个 Agent turn 发送的数据

根据请求和已启用工具，Lyra 会向所选模型发送提示词、系统指令，以及相关附件、文件、图片、网页、记忆、工具结果、项目与 Git 上下文、设备上下文、屏幕信息、时区和经授权的位置上下文。

当前测试版还会从操作系统及常见开发配置（例如 Git、SSH 注释、npm/pip、VS Code 或 Cursor）读取本机身份线索，并推导可能的姓名、邮箱、用户名和年龄上下文提供给模型。这是当前行为，不是匿名账户枚举。

{/* section:cloud-byok-custom */}
## 云端、BYOK 与自定义端点

BYOK 改变的是认证或付费凭证，不会阻止服务商接收请求数据。自定义兼容端点会接收完成请求所需的同类数据，应被视为独立数据接收方。请核验运营者、TLS、日志、保留与训练政策。

{/* section:local-models */}
## 本地端点

回环或设备内端点可以让模型推理留在本机，但 Lyra 仍可能因网站、搜索建议、更新、账户、扩展、MCP 或位置查询连接其他服务。应逐项检查功能，而不是只依赖“本地模型”标签。

{/* section:provider-register */}
## 使用敏感数据前

阅读服务商当前的隐私与保留条款，减少附件，移除秘密，并选择合适的账户或地区。Lyra 维护的服务商信息应以法律站点的登记表为准；未填写项表示尚未确认，不能自行假设。
