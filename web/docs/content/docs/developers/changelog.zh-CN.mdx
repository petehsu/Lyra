## 2026-07-28

Lyra Desktop `0.1.x` 测试版文档契约基线：

- 发布 MCP configuration、Skill frontmatter、语言包 catalog、UIUX Pack manifest 与 Software Capability manifest 的 v1 Schema 和 fixture。
- MCP、Skills 与语言包标为 Supported。
- UIUX Pack、Software Capabilities 与 CLI 标为 Preview。
- 定义已实现 MCP 子集：`initialize`、`notifications/initialized`、`tools/list` 与 `tools/call`。
- 明确 Skill 权限字段只是声明性元数据。
- 明确 UIUX 代码受信任且不在沙箱中。
- 使用 Software Capabilities Preview manifest 取代旧 LCP/公开 SDK 表述；Lyra 不提供公开 npm SDK。
- 为 Supported 契约建立同 major 兼容和旧 major 六个月保留政策。
