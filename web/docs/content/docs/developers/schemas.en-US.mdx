## Contract metadata

Each Schema includes `x-lyra-contract` with the contract status, version, applicable app version, and verification date. These annotations do not change JSON Schema validation.

{/* section:validation */}
## Validate locally

Run:

```bash
pnpm --filter @lyra/docs-web contracts:check
pnpm --filter @lyra/docs-web mcp:smoke
```

The checks validate every fixture, compare paired docs, exercise the exported production validators that can be loaded directly, and run the MCP handshake fixture. They do not publish a package or change the production parser.

{/* section:no-sdk */}
## Schema, not SDK

The Schema describes the accepted document shape. It does not grant access to internal APIs and does not create a public npm SDK. If a Schema and an example disagree, the Schema and the current documented status take precedence; report the mismatch as a docs defect.
