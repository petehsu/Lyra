## 契约元数据

每个 Schema 都包含 `x-lyra-contract`，标明契约状态、版本、适用应用版本和核验日期。这些注解不改变 JSON Schema 校验语义。

{/* section:validation */}
## 本机校验

运行：

```bash
pnpm --filter @lyra/docs-web contracts:check
pnpm --filter @lyra/docs-web mcp:smoke
```

检查会校验所有 fixture、比较双语文档、调用能够直接加载的生产 validator，并运行 MCP 握手 fixture。它不会发布 package 或改变生产 parser。

{/* section:no-sdk */}
## Schema，不是 SDK

Schema 描述可接受文档结构，不授予内部 API 访问，也不构成公开 npm SDK。如果 Schema 与示例冲突，以 Schema 和当前文档状态为准，并把冲突作为文档缺陷报告。
