## 打开方式

文件管理器中双击文件后：

1. 在工作区新标签打开 `file-editor`。
2. 同路径标签单例去重：已打开则直接激活。
3. 目录双击行为保持为进入目录，不混淆。

## 保存闭环

V1 已落地三种保存触发：

1. 手动保存：`Ctrl/Cmd + S`
2. 停顿自动保存：默认 800ms
3. 失焦自动保存

写入由 Rust 层做原子保存与 revision 冲突保护。

## 智能能力基线

当前智能能力：

1. 语法高亮
2. 自动补全
3. 诊断提示

覆盖语言：`TS/JS`、`Rust`、`Python`。
