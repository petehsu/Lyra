## Lyra 是什么

Lyra 是一个把浏览器标签、搜索、文件、编辑器、终端、Git 与 Agent 放进同一工作区的桌面软件。一个工作区可以容纳多种标签页，Agent 会话也可以绑定项目目录。

代码层面覆盖 macOS、Windows 与 Linux；实际发布的安装包可能晚于平台实现，请以版本页面列出的产物为准。

{/* section:local-first */}
## 本地优先，不是完全本地

工作区、会话、浏览器 profile、设置、日志、下载文件、凭证和扩展登记主要保存在本机。但使用相应功能时，Lyra 仍会连接所选 AI 服务商、网站、搜索建议、更新、语言包、Skills 来源、MCP 端点、账户服务及位置查询服务。

“本地优先”不表示所有数据都留在设备上。添加敏感材料前请阅读[模型与服务商](./models-providers)。

{/* section:beta-boundary */}
## 免费测试版边界

当前产品是免费测试版，不包含订阅、续费、税费、退款、服务额度、可用性或企业支持承诺。请备份重要项目，并在确认前把 AI 与自动化输出视为不可信内容。

{/* section:status-model */}
## 功能状态

- **Stable：**经过测试和文档化、可正常使用的测试版核心能力，但没有付费 SLA 或可用性保证。
- **Preview：**可用于评估，但可能在 Changelog 告知后发生变化或破坏兼容。
- **Experimental：**不完整、变化频繁，可能大幅重做或移除。

Workbench 和 Solo Agent 核心流程在测试版中标为 Stable；UIUX Pack、Software Capabilities 和面向用户的 CLI 命令标为 Preview；Oma 多 Agent 模式标为 Experimental。同一个构建中的不同能力可以有不同状态。
