## 使用要点

1. 按住任意标签拖动，可直接调整顺序。
2. 标签超出可视范围时，把鼠标放在标签栏上滚轮即可横向滚动。
3. 左侧按钮用于后退/前进，右侧 `+` 用于新建标签。

## 设计原则

1. 激活标签与内容区保持连续感，不做割裂边界。
2. 交互保持熟悉，不引入额外学习成本。
3. 信息密度优先，但不牺牲可读性和可点击性。
