## What these docs cover

These are the public docs for the closed-source Lyra Desktop application. They document capabilities present in the current beta and the interfaces intentionally offered to external developers.

Internal implementation details—desktop process bridges, runtime sockets, storage schemas, internal packages, and Agent ABI—are not public interfaces. Repository contributors should use the internal engineering docs instead.

{/* section:status-words */}
## Status words

Product maturity uses **Stable**, **Preview**, and **Experimental**. Stable means the beta feature is intended for normal use; Preview may change; Experimental is incomplete or high-change and should not carry critical work.

External interface contracts use **Supported** and **Preview**. A Supported developer contract remains compatible within the same major version. Preview contract changes are recorded in the developer Changelog but are not guaranteed backward compatible.

Lyra is a free beta. “Stable” or “Supported” does not create a paid SLA, uptime promise, or guarantee that a third-party service will remain available.
