Lyra is an AI-native workbench, not a browser add-on and not a thin IDE shell.

This page gives you the shortest path: onboard quickly, then understand architecture and boundaries.

## What Lyra is trying to do

1. Unify browsing, coding, files, terminal, and AI collaboration in one workspace.
2. Use a tab model to host real software capabilities, not just more web pages.
3. Keep performance and evolvability first to avoid early monolith regressions.

## What you will find here

1. Run and develop: startup, debugging, and troubleshooting.
2. Architecture and boundaries: responsibilities, dependency rules, guardrails.
3. Workbench model: tab lifecycle, panel coordination, drag transfer.
4. File and editor stack: file manager, file editor, LSP intelligent core.
5. Cross-platform readiness: Linux compatibility and diagnostics pipeline.
