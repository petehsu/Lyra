重塑 Agent 的四个支柱维度

我们拒绝拼凑与补丁，用 Rust 的安全和结构化的状态机重构 Agent 本地执行体验。

结构化本地记忆 (`agent-memory`)

全系采用本地 SQLite 存储，提炼核心 RuntimeTurn 状态机和 Pinned 上下文层。彻底杜绝摘要泄漏，保障长工具链及重载崩溃下的可靠恢复。

可视化浏览器跟随 (Lumen Mode)

内嵌的 Lumen 浏览器支持“跟随/隐式”双轨机制。前台工作区真实呈现 Agent 的点击、输入、焦点与等待，实现人机协同的完美同屏。

高性能 Rust Native 引擎

主守护进程 `lyrad` 基于强安全、高并发 Rust 重构。剥离 JS 历史包袱，处理高频数据流投影与深度代码解析，前台响应如丝般顺滑。

细粒度安全与隐身沙箱

建立零信任安全网关。Agent 发起文件编辑、Shell 运行或公网数据请求时，均会触发本地高阻尼授权面板，给予用户绝对否决权。

高精度的分层系统蓝图

从 UI 投影到 Native 存储，Lyra 坚守清晰而严格的单向依赖与进程隔离原则。

Shell / UI Layer

apps/desktop

基于 Electron & React 的前台。完全只读消费 `Timeline Projection` 与结构化 DTO，坚决不参与任何底层状态修改。

Process & Routing

crates/lyrad

轻量进程与 IPC 管道。负责双向事件广播、状态推送、命令校验，彻底杜绝 jcode 内部命名向 UI 层暴露。

Orchestration & Rules

crates/lyra-agent-runtime

核心编排系统。通过 SQLite 强类型承载 Session，驱动 Context Assembler 构建模型输入，拒绝混淆 timelines。

Agent Primitives

crates/lyra-agent-kernel

内置 AI 内核实现。封装具体的 LLM 请求、工具集执行引擎与流程压缩，不反向依赖任何 UI 与上层视图模型。
