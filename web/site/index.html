Features

Everything your desktop needs

A single AI agent that understands your screen, runs your terminal, browses the web, and manages your files — all locally.

🤖

Agent Runtime

Rust 原生 agent 内核，支持多轮对话、工具调用、权限控制与任务编排。低延迟，高可靠。

🌐

Browser Control

内置 Chromium 浏览器，支持页面理解、DOM 操作、表单填写和自动化导航。像人一样浏览网页。

💻

Terminal

智能终端管理，支持多会话、命令补全、输出解析与错误恢复。安全沙箱内执行。

📁

File Manager

原生文件浏览、搜索、预览与批量操作。理解项目结构，智能定位目标文件。

🔌

Multi-Provider

支持 OpenAI、Anthropic、Google Gemini、xAI、本地模型等多 provider。自由切换，一键配置。

🧩

Plugin System

可扩展的工具与 UIUX 插件架构。从软件商店安装，或用 TypeScript 编写自定义插件。
