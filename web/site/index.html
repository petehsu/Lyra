Features

Everything You Need in One Platform

From multi-agent orchestration to desktop integration — Lyra brings together every tool you need to build with AI.

Multi-Agent Collaboration

Orchestrate multiple AI agents working together on complex tasks. Each agent brings specialized capabilities — coding, browsing, research, and more.

Code Intelligence

Full code understanding across your entire codebase. Edit, refactor, and generate code with precision using context-aware AI.

Browser Automation

Agents that can browse the web, interact with pages, extract data, and fill forms — all under your supervision and control.

Extensible Tool Chain

Connect any API, CLI, or service as a tool. Lyra's plugin architecture lets you extend agent capabilities with minimal code.

Security Sandbox

Every agent runs in an isolated sandbox with granular permissions. Review, approve, or deny each action — you stay in control.

Desktop Integration

Native macOS, Linux, and Windows support. Agents can interact with your file system, terminal, and desktop applications.

How Lyra Works

Code Demo

See It in Action

A simple multi-agent workflow — Lyra handles the orchestration, you get the result.

# create_agent.py

from lyra import Agent, ToolSet

# Define a research agent with code + browser tools
agent = Agent(
    name="research-bot",
    model="claude-3-opus",
    tools=ToolSet(
        code_edit=True,
        browser=True,
        terminal=True,
        filesystem="~/projects/*"
    ),
    instructions="You are a research engineer. Browse docs, write code, and run tests."
)

# Run the agent with a complex task
result = agent.run(
    "Find the latest API docs for OpenAI GPT-4o, write a summary, and save it to README.md"
)

print(result.summary)
# → "Browser searched docs, extracted key changes, wrote README.md"
