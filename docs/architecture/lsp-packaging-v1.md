# LSP Packaging V1

## Goal
- Ship Lyra file-editor intelligent core with predictable cross-platform behavior.
- Keep runtime startup deterministic: bundled binaries first, local toolchain fallback second.

## Three-Platform Packaging Strategy

### 1. Rust Analyzer (native executable)
- Distribution source: `rust-lang/rust-analyzer` release assets.
- Bundle matrix (OS x arch):
1. `linux-x64`
2. `linux-arm64`
3. `darwin-x64`
4. `darwin-arm64`
5. `win32-x64`
6. `win32-arm64`

Runtime resolution order:
1. explicit env `LYRA_LSP_RUST_ANALYZER`
2. bundled target path in `resources/lsp/<target>/...`
3. fallback PATH (`rust-analyzer`)

### 2. TypeScript / JavaScript
- Primary runtime: app-local `node_modules/.bin/typescript-language-server` + `typescript`.
- Optional override: `LYRA_LSP_TYPESCRIPT_SERVER`.

### 3. Python
- Primary runtime: app-local `node_modules/.bin/pyright-langserver`.
- Optional override: `LYRA_LSP_PYRIGHT`.

## Artifact Directory Contract

```text
apps/desktop/resources/lsp/
  manifest-rust-analyzer.json
  linux-x64/rust-analyzer
  linux-arm64/rust-analyzer
  darwin-x64/rust-analyzer
  darwin-arm64/rust-analyzer
  win32-x64/rust-analyzer.exe
  win32-arm64/rust-analyzer.exe
```

Rules:
1. One target directory contains one rust-analyzer executable only.
2. Manifest must be regenerated by installer script after each update.
3. Runtime resolver only trusts files under this contract and explicit env override.

## Build / Release Workflow
1. Install bundled rust-analyzer matrix:
   - `npm --prefix apps/desktop run lsp:bundle:rust-analyzer`
2. Build desktop native modules:
   - `npm --prefix apps/desktop run native:build`
3. Run release preflight:
   - `npm --prefix apps/desktop run lsp:preflight`
4. Run full quality gates:
   - `npm --prefix apps/desktop run typecheck`
   - `npm --prefix apps/desktop run test`

## Preflight Guarantees
- Required npm dependencies exist: `typescript`, `typescript-language-server`, `pyright`.
- Local binaries exist in `apps/desktop/node_modules/.bin`.
- rust-analyzer bundle exists for current target (or all targets with `--all-targets`).
- rust-analyzer files are executable on non-Windows hosts.
- Manifest exists and is parseable.
