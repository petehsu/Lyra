## 标签页现在是什么

| 概念 | 职责与边界 |
| --- | --- |
| 标签页 ID | 标识一个页面。URL 相同也可能是不同表单、不同草稿，不能据此当成同一个实例 |
| 任务当前页 | 按会话与 live/isolated 模式分别记录。用户切换前台、胶囊更新，都不改写它 |
| 元素所属页 | 地图里的真实元素引用保留所属页；访问邮箱后仍能凭原引用回到验证页。显式 tabId 与引用冲突、一次输入跨页，都拒绝执行 |
| 工作台前台页 | 用户当前查看的页面。只有任务尚未建立选择时才参与初始定位 |
| 胶囊／预览 | 展示状态，不作为页面存在性或操作路由的依据 |
| 隐藏、休眠页 | 拓扑中仍存在的页面可按需恢复；任务使用期间保留实例。不能把休眠误判成关闭 |
| 已关闭页 | 明确失败并列出可选页面；不悄悄改到前台，不用旧预览复活它 |
| 任务使用权 | 与单次操作成功、是否显示跟随效果分别管理。一个任务结束不能释放另一个任务还在使用的页 |

### 导航规则

- `navigate(url)` 默认另开任务标签页；本任务已经打开、仍存在且 URL 完全匹配的页面可复用。
- `navigate(url, tabId)` 明确替换指定页面；`newTab: true` 强制另开，`newTab: false` 明确在任务当前页导航。
- `map(tabId)` 选择并读取保留下来的页面。后续无 tabId 的操作跟随任务选择。
- 跳转只有在目标文档提交并就绪后才报告 ready。初始空白页的就绪事件不能冒充目标网站已加载。超过观察预算返回 pending，要求读当前页确认，不能自动重复跳转。
- 浏览器后退／前进调用 Electron 的真实历史接口；没有历史或未确认完成都不会报成成功。不同标签页之间应选择页面，后退不会替代切页。

显式替换页面仍然可能离开未完成表单，这是调用者明确选择的行为。系统默认保留表单，并未禁止所有站内导航。页面身份与观察记录属于当前运行时，不承诺应用重启后恢复未提交网页内部状态。

## 参考实现与工作边界

- [Playwright Pages](https://playwright.dev/docs/pages)：页面由独立 Page 对象标识，操作不要求用户把它切到前台。采用的边界是“前台焦点不替代任务页面身份”。
- [Electron navigationHistory](https://www.electronjs.org/docs/latest/api/navigation-history)：浏览器历史属于 webContents 的导航接口，不能只发送网页键盘事件并假定浏览器后退。
- 本地 `參考/ZCode/packages/shared/src/browser-use/backend.ts`：连接身份／generation 与浏览器对象缓存分离；不把另一个连接的缓存对象当成当前后端。采用身份边界，不照搬其交互实现。
- 本地 `參考/opencode/packages/core/src/session/compaction.ts`：控制历史和摘要的工作范围。本次没有盲目调整全局上下文预算，也没有删除 provider 必需的思考回传内容。
