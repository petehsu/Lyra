## ADR format

Each decision includes:

- audience, date, status, and last verification date;
- context;
- decision;
- alternatives considered;
- consequences, migration, enforcement, or acceptance evidence as applicable.

Do not change an accepted decision's historical meaning. Add a new ADR and mark
the old one Superseded. A Proposed ADR is not implementation evidence.
