# Lyra LSP Runtime Artifacts

This directory stores bundled language-server binaries used by Lyra desktop packaging.

## Directory Contract

```text
apps/desktop/resources/lsp/
  manifest-rust-analyzer.json
  linux-x64/rust-analyzer
  linux-arm64/rust-analyzer
  darwin-x64/rust-analyzer
  darwin-arm64/rust-analyzer
  win32-x64/rust-analyzer.exe
  win32-arm64/rust-analyzer.exe
```

- `manifest-rust-analyzer.json`: install metadata generated by `tools/lsp/install-rust-analyzer.ts`.
- Each target folder contains one rust-analyzer executable for that platform/arch.
- TS/JS and Python language servers are resolved from app-local `node_modules/.bin` during development/packaging.

## Commands

From repository root:

1. Install rust-analyzer artifacts (all targets):

```bash
tsx tools/lsp/install-rust-analyzer.ts --all
```

2. Run release preflight:

```bash
tsx tools/lsp/preflight-lsp.ts --all-targets
```
